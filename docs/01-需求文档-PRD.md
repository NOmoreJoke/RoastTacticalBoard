## 1. 产品 Goal（一句话）

> **做一个"热血动漫风"的团体运动吐槽工具+社区：让球友在赛后 1 分钟内，把队友（或野球场的神秘路人）的迷惑选择和战术跑位，还原成一张可以快速分享的吐槽战术板；再通过分享把好友拉进"球队圈子"，圈内 @ 吐槽积累"吐槽值"，形成圈子内部吐槽排行榜——用"随缘射手""吐饼大师"这类无攻击性的恶搞称号，让吐槽成为增进感情的社交货币，而不是网络暴力。**

### 1.1 北极星目标（North Star）

- **北极星指标**：每周被分享出去的吐槽板数量（板/周）。
- **护栏指标**：被举报内容占比 < 0.5%；次周留存 ≥ 25%。

### 1.2 目标用户与画像

| 画像 | 场景 | 核心诉求 |
|---|---|---|
| 业余球队组织者（队长） | 每周固定球局，赛后群里最活跃 | 把赛后复盘变成节目效果，提升球局凝聚力 |
| 野球局常客 | 临时拼场，三五个好友+一堆路人 | 吐槽共同遇到的"路人大神"（不认识、没好友关系） |
| 被吐槽者本人 | 被 @ 的快乐受害者 | 反击、认领称号、展示自己的"吐槽值" |

### 1.3 核心用户故事（按优先级）

1. **赛后 1 分钟出图**：作为队长，我想在赛后立刻把"那次传丢了还摊手"的跑位画出来，生成一张带称号的吐槽图，发到群里。
2. **吐槽队友**：作为球员，我想给某个队友贴上"随缘射手"的称号，并 @ 他，让群友点赞（认同），他的"吐槽值"上涨。
3. **吐槽野球场路人**：作为野球常客，我不认识那个人，我想创建一个**虚拟名字+虚拟角色**（如"帽衫神秘人·疑似退役职业哥"）来吐槽他。
4. **拉好友进圈子**：作为队长，我想创建"球队圈子"，拉好友进入，只有圈内人可见圈内吐槽板。
5. **圈子吐槽排行榜**：作为圈内成员，我想看本周圈内"吐槽值"排行榜：谁是本周吐饼大师、谁被吐槽最多、谁嘴最毒。
6. **自定义我的形象和标签**：作为用户，我想自定义我在运动中的形象（头像、号码、颜色）和我想要的标签/称号，被 @ 时展示的是我认可的形象。
7. **同名同角色不混淆**：圈子里有两个"阿强"时，用吐槽场景和标签区分他们（如"中锋阿强·三不沾大师" vs "后卫阿强·越位常客"）。

## 3. MVP 功能需求明细（V0.1，本期开发）

### 3.1 功能清单与优先级

| 编号 | 功能 | 优先级 | 说明 |
|---|---|---|---|
| F1 | 运动类型选择（篮球/足球） | P0 | MVP 仅两种，架构支持扩展 |
| F2 | 战术板编辑器（画布） | P0 | 球场、球员、路线箭头、吐槽气泡 |
| F3 | 球员/角色系统 | P0 | 队友形象 + 虚拟路人角色 |
| F4 | 吐槽称号标签库 | P0 | 预置恶搞称号 + 自定义标签 |
| F5 | 吐槽气泡（文本+标签+@对象） | P0 | 复刻真实赛后吐槽语言场景 |
| F6 | 吐槽图生成与快速分享 | P0 | 保存相册/分享图片/分享给好友/分享码 |
| F7 | 我的板管理 | P1 | 本地列表、编辑、删除、复制 |
| F8 | 我的形象与标签自定义 | P1 | 头像色+表情+号码、自定义称号 |
| F9 | 吐槽值（本地版）与本机吐槽榜 | P1 | 点赞计数、按角色聚合、排行榜页 |
| F10 | 分享码导入 | P1 | 无后端前提下的板跨设备流转 |

### 3.2 详细需求

#### F1 运动类型选择
- 首页两张大卡：🏀 篮球 / ⚽ 足球，热血动漫风描边+速度线。
- 选择后直接进入新建板流程（选运动 → 起标题 → 进编辑器）。
- 板创建后运动类型不可更改（场地不同）。

#### F2 战术板编辑器
- **画布**：Canvas 2D 绘制球场底图；篮球默认半场，足球默认半场（可切换全场，MVP 仅半场）。
- **球员**：圆形 token（自定义色+表情+号码），触摸拖拽移动；篮球板预设 5v5、足球板预设 7v7（可增删，篮球最多 5×2，足球最多 11×2，分主客两队配色）。
- **路线箭头**：三种——传球线（实线）、跑位线（虚线）、出手/射门线（带"咚!"爆炸终点）。拖拽绘制，可选中删除；支持撤销最近一步（仅箭头操作）。
- **吐槽气泡**：漫画对话泡样式，包含吐槽文本（≤ 60 字）+ 称号标签 + @ 对象（0..n 个球员）；可拖拽摆放。
- **板信息**：标题（≤ 20 字）、运动类型；标题会进分享卡片文案。
- **保存**：本地保存（编辑中自动暂存，退出前提示保存）。

#### F3 球员/角色系统
- 两种来源：
  - **我的好友/队友**：从"我的球员名单"选择（名单在个人中心维护，MVP 存本机）；每个球员有：名字（≤ 8 字）、形象（色+表情+号码）。
  - **虚拟路人**：当吐槽对象不是熟人时，一键生成虚拟角色：随机组合「形象 + 前缀称呼（帽衫神秘人/野球大叔/自称球王哥/……）+ 特征称号建议」。同名同角色的情况，通过场景与标签自然区分（板上同名的自动追加号码后缀）。
- 球员可被打上 0..n 个吐槽标签（见 F4）。

#### F4 吐槽称号标签库（无攻击性恶搞）
- 预置库（示例，持续扩充）：
  - 篮球：随缘射手、三不沾艺术家、传球找空气、篮板黑洞、折返跑王者、关键时刻隐身、教练附体、犯规小能手、抢断自己人、体力怪
  - 足球：吐饼大师、射正王、越位常客、传球找观众、龟速回防、门将刺客（踢自家门）、任意球自由人、步频元帅、饮水机守护神、假摔影帝
  - 通用：嘴强王者、战术大师（嘴上）、复盘之神、下次一定、团建之星
- **自定义标签**：≤ 8 字；创建时经本地"攻击性词库"过滤，命中即拒绝并提示（MVP 本地词库，V2 服务端词库+内容安全接口）。
- 所有标签带 emoji 与类别（技术/意识/体能/心态/名场面），输出到吐槽图。

#### F5 吐槽气泡
- 组成：文本 + 标签（可多选）+ @ 对象（可多选球员）。
- 典型模板（一键填充降低输入成本）："这球你敢传？""跑位是我带你飞的""这脚射门我给 9.9 分，0.1 分怕你骄傲"。
- 每板吐槽气泡上限 10 个（保证画面与性能）。

#### F6 吐槽图生成与快速分享
- **生成图**：整板合成 750×1000 海报：标题、球场、球员、箭头、气泡、"纯属娱乐·友尽不负责"水印。
- **分享路径**：① 保存到相册；② 微信图片分享菜单；③ 小程序卡片分享（好友/群）；④ 复制"吐槽码"（自研编码，无后端也可完整转移板数据）。
- **导入**：首页"输入吐槽码"粘贴导入，校验版本与结构，失败给出可读错误。

#### F7 我的板管理（本地）
- 列表：封面缩略（运动+标题+更新时间+吐槽值）、置顶最近编辑；支持删除（二次确认）、复制副本、重命名。

#### F8 我的形象与标签自定义
- 我的形象：昵称 + 形象（12 色 × 24 表情 × 号码 0-99）。
- 我的球员名单（本地）：维护常一起打球的队友形象，编辑器直接选用。
- 我的称号：从预置库勾选 + 自定义，编辑器 @ 自己时默认带出。

#### F9 吐槽值（MVP 本地版）
- 详情页每条吐槽可点"太真实了😅"（本机点赞），吐槽值 = 该板所有吐槽被认同数之和。
- **本机吐槽榜**：按角色聚合本机所有板的吐槽值，Top 20 榜单（榜样式：热血漫画领奖台）。
- 明确限制：MVP 点赞为本机数据，跨设备点赞在 V0.2 云端化后生效（分享码导入的板带初始值）。

#### F10 分享码
- 版本化编码：`RTB1.<base64url(JSON)>`，JSON 含 schemaVersion、板完整数据与校验和。
- 解码容错：去空白、容错 base64 变体、结构校验失败时提示具体原因。

### 3.3 非功能需求（MVP）

| 维度 | 要求 |
|---|---|
| 性能 | 编辑器拖拽 ≥ 45fps；生成吐槽图 ≤ 1.5s；冷启动 ≤ 2s |
| 兼容 | 微信基础库 ≥ 2.29；iOS/Android 主流机型；适配小屏（iPhone SE）至平板 |
| 隐私合规 | MVP 不登录、不收集个人信息、无网络请求，数据仅存本机 → 通过平台隐私检查最简路径 |
| 内容安全 | 本地敏感词过滤（标签+吐槽文本）；导出图水印"纯属娱乐"；V2 起服务端 msgSecCheck |
| 可用性 | 核心路径（新建→编辑→出图→分享）≤ 8 步；全部按钮有可触达的反馈 |
| 可扩展 | 运动类型、标签库、球场配置全部数据驱动，新增运动零改架构 |

## 4. V0.3 球队圈子（本期只做数据结构预留，不开发）

- **圈子**：名称、头像、运动类型、成员（上限 50）、邀请码/邀请卡片。
- **圈子时间线**：圈内发表的吐槽板流；仅成员可见。
- **@ 与吐槽值**：圈内点赞（"认同/哈哈/扎心了"三种反应）驱动被 @ 者吐槽值；吐槽值分级（青铜吐王→王者吐王），赛季重置可选。
- **同名区分**：同圈子同名字的成员强制要求差异化标签（系统提示+推荐），展示为「名字·标签」组合。
- **内部排行榜**：日/周/总榜三类：被吐槽榜（谁最惨）、嘴炮榜（谁最能吐）、名场面榜（单板点赞最高）。

## 5. 风险与对策

| 风险 | 等级 | 对策 |
|---|---|---|
| UGC 平台审核风险（微信对社区类小程序资质要求高） | 高 | MVP 纯工具无 UGC 公开分发，先以工具类目过审上线；社区功能在具备类目资质后灰度 |
| 吐槽演变为网络暴力 | 高 | 无攻击性称号设计原则、本地+服务端敏感词双过滤、举报与拉黑（V0.3）、社区公约前置确认 |
| 小程序类目与备案流程不熟 | 中 | README 附《明日备案部署操作指南》（见 §8） |
| Canvas 多机型渲染差异 | 中 | 统一使用 Canvas 2D 新接口 + 逻辑坐标（百分比），导出图固定画布 |
| 无后端导致分享体验受限 | 中 | 分享码兜底完整数据转移；图片分享为主路径 |

## 6. 验收标准（MVP 整体）

1. 全新设备 3 分钟内完成「选运动 → 画板 → 打标签 → 生成吐槽图 → 保存相册」全流程。
2. 分享码在两台设备间无损往返。
3. 全部单元测试通过（详见 04 文档），核心逻辑覆盖率 ≥ 80%。
4. 微信开发者工具真机预览无阻断性 bug。
