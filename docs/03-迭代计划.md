## ITL-0：V0.1 MVP（今天完成）✅ 本次交付

**范围**（对应 PRD F1-F10）：

- [x] 工程骨架 + 文档四件套（PRD/设计/迭代/测试CI）
- [x] utils 纯逻辑层：board / tags / safety / avatar / courts / share / storage / format
- [x] 页面：index / editor / detail / profile / ranking
- [x] 编辑器：球场画布、球员拖拽、三种箭头、吐槽气泡、撤销、路人角色生成
- [x] 吐槽图导出 + 四路分享（相册/图片/卡片/吐槽码）+ 导入
- [x] 本机吐槽值 + 本机吐槽榜
- [x] 我的形象/球员名单/自定义标签
- [x] Jest 单测 + ESLint + GitHub Actions CI
- [x] README 与《备案部署操作指南》

**明确的 MVP 边界（不做）**：无登录、无网络请求、无云端、无圈子、无公开分发；点赞仅本机。

**验收门槛**：见 PRD §6；单测全绿 + 覆盖率 ≥ 80%（core 逻辑）+ 开发者工具编译零错误。

## ITL-1：上线冲刺（第 1-2 周）

- 真机适配清单：iOS/Android 主流机型过一遍编辑器拖拽与导出图（小屏气泡重叠防护）。
- 提审材料：类目「工具-效率」、截图、隐私协议（MVP 不收集，声明仅本地存储）。
- 审核常见问题预案：名称与简介一致性、无诱导分享文案复查。
- 本地统计：分享次数/出图次数（本地计数，V0.2 上报）。
- **里程碑**：小程序过审上线，可搜索使用。

## ITL-2：V0.2 云开发（第 3-4 周）

- 微信登录（openid）、云数据库集合：users / boards / likes。
- 板云端保存与「分享卡片直达」（分享路径带 boardId，好友点开即看）。
- 点赞跨设备生效；吐槽值云端聚合。
- 备份与恢复（换手机不丢板）。
- **里程碑**：分享出去的卡片可直达查看与点赞，吐槽值开始跨设备积累。

## ITL-3：V0.2.x 内容安全与体验（第 5-6 周）

- 服务端 msgSecCheck（文本）/ imgSecCheck（导出图）接入；举报入口 v1。
- 全场地图、半场/全场切换；更多漫画模板气泡与贴纸。
- 分享图加小程序码（回流）。
- **里程碑**：具备 UGC 前置合规能力，为圈子扫清审核障碍。

## ITL-4：V0.3 球队圈子（第 7-10 周，两周一个双迭代）

- 圈子 CRUD、邀请卡片/邀请码入圈、成员管理（≤50）。
- 圈子时间线（圈内板流）、@队友通知（订阅消息）。
- 三种反应（认同/哈哈/扎心了）与吐槽值分级（青铜→王者吐王）。
- 圈子排行榜：被吐槽榜 / 嘴炮榜 / 名场面榜（日/周/总）。
- 同名区分：同圈同名强制差异化标签 + 「名字·标签」展示规范。
- **里程碑**：一个真实球队完整跑通「画板→圈里发→互动→上榜」闭环。

## ITL-5：V1.0 公开社区（第 11-14 周）

- 公开广场（可匿名板）、热门推荐（点赞增速 + 时效衰减）、话题标签。
- 周称号系统（随缘射手周榜第一名获得专属徽章）。
- 内容审核后台（先复用云开发控制台 + 人工巡查）。
- **里程碑**：社区形态跑通，开始看北极星指标。

## 人员与工作量假设

- 当前为单人 + AI 结对开发。每个迭代预留 20% 时间处理线上反馈与审核沟通。
- V0.3 起建议增加 1 名兼职工匠（UI 打磨与审核后台巡查）。

## 风险触发的计划调整预案

| 触发条件 | 调整动作 |
|---|---|
| ITL-1 审核被拒 > 2 次 | 暂停 V0.2，优先解决合规（类目/资质） |
| MVP 上线 2 周分享数 < 100 | 回到留存设计：模板库丰富度与出图速度优先于社交功能 |
| 圈子需求强于预期 | ITL-4 提前，V0.2 砍「全场地图」 |
